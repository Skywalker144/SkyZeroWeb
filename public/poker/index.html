统计口径

一次请求是 LLM 的一次决策；一手牌包含从发底牌到结算的所有请求。总 token = API 返回的输入 + 输出，输出包含思考 token。生成 TPS = 输出 token ÷ 从首个内容 / 思考片段到最后一个片段的时间；端到端耗时另列。缺失 usage 时显示“未知”，不估算 token。

网络断联、超时及临时服务错误会在 2 / 4 / 8 秒后自动重试，最多 3 次；可随时取消。每次重新请求可能产生 API 用量。重试和失败请求也计入时间；未返回 usage 的请求不能计入准确 token 总数。

裁判手册
谁先行动？

二人局中，按钮位（BTN）付小盲，翻牌前先行动；翻牌、转牌、河牌都由大盲先行动。每手按钮轮换。

跟注、加注与全下

加注金额表示“本轮累计投入到多少”，不是额外投入多少。最小加注增量等于上一次完整下注 / 加注的增量，最小下注为 1 BB（2 筹码）。不足最小加注时，只能以全部剩余筹码全下。

双方筹码不等时，未被跟注的多余筹码退回；本二人局无需建立边池。有人全下且不再有待跟注动作时，系统发完公共牌并摊牌。

怎样比较大小？

从 2 张底牌和 5 张公共牌中任选最佳 5 张；可以用 0、1 或 2 张底牌。牌型相同时逐张比较点数（kicker），花色不分大小。A2345 是最小顺子。

同花顺 ＞ 四条 ＞ 葫芦 ＞ 同花 ＞ 顺子 ＞ 三条 ＞ 两对 ＞ 一对 ＞ 高牌。

从 PIG 到 IIG

系统掌握整副牌；每名玩家只观察自己的底牌与公共历史。不要把对手理解成一手确定的牌，而是一组可能手牌（range）。这里的 LLM 是练习对手，不是 GTO 求解器。
